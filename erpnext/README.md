# RootedOps ERPNext Configuration Pack

Prepared for:
- Dank Mushrooms, LLC
- Rooted Psyche

## What this pack does
This pack is designed to accelerate a lean ERPNext/Frappe HR rollout with:
- two companies in one site
- company-specific charts of accounts
- cost centers, departments, designations, projects, suppliers
- expense claim types, asset categories
- employee/bank account starter templates
- a manual payroll blueprint for a first hourly employee at Dank Mushrooms, LLC

## Important warnings
1. Import the **Chart of Accounts** only on a company with **no transactions yet**.
2. U.S. federal and Colorado withholding should be reviewed by a payroll accountant before your first live payroll run.
3. This pack intentionally keeps the payroll setup lean. It is not tax advice.
4. Before importing anything, enable Accounting → Settings → Enable Multi-Company
