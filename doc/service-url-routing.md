RootedOps `401fd5d`, SignatureGate main and the restored test2 datasource inventory
were reviewed on 2026-10-31. This document describes configuration, not production
rollout approval. Never replace an existing private `.env` with the example.

| Clover / Google / Airtable / Ecwid | provider-specific URLs | external third parties, not Docker service names |

The existing SignatureGate workflows choose **private, public, hardcoded internal**
in that order. Compose must export blank absent private overrides rather than
inject a hardcoded private value first. The example explicitly supplies private
defaults, so a copied example retains same-network routing. To use public fallback,
an operator must deliberately leave the private override blank; an unreachable
nonempty private URL does not trigger an automatic retry to public. This is value
selection, not network failover. Public fallback is not appropriate for isolated
test2 if it points to production.

No `_PRIVE` or `_PUBLIC_URI`/`_PRIVATE_URI` spellings were found in the reviewed
RootedOps source. Keep supported application-specific names (`NC_PUBLIC_URL`,
`ERPNEXT_INTERNAL_URL`, `NEXT_PRIVATE_*`) instead of renaming them mechanically.
Removed two unused example-only Documenso knobs: `DOCUMENSO_PRIVATE_JOBS_PROVIDER`
and `DOCUMENSO_PRIVATE_INTERNAL_WEBAPP_URL`. They never controlled Compose;
Documenso's own local job provider/internal webapp URL remain fixed in Compose.
Existing private files may retain those unused keys; no secret migration is needed.

Fresh-host generation now applies its selected suffix to Documenso, Listmonk,
both LibreChat URLs, MushroomProcess Appsmith links and Minecraft host as well as
ERPNext/NocoDB/n8n/scheduling. Appsmith page IDs still require operator review.
`MP_REGULATED_BUSINESS_URL` is an intentional external business link. Existing
generated deployments are not rewritten or regenerated by this change.
