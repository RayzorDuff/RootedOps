# RootedOps 1.5.21

RootedOps Issue #1 adds read-only ERPNext bank-account discovery for
SignatureGate cash-deposit preparation.

Rooted Psyche ERPNext Bank Accounts through n8n, using the canonical Bank
Account document name as the stored value. Plaid integration IDs and credentials
are not exposed.
